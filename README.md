# Android Device Control Center

Android 16-first, local-first device intelligence and guided-control application.

The project is in **Phase 2: capability and permission center**.

Phase 1 foundation and the RAM/thermal/storage/access snapshot are verified in CI and on the target Android 16 phone. The first physical inspection of the factual battery snapshot exposed an invalid OEM voltage value; a validation/fallback correction is in progress and the battery milestone is not verified.

## Product contract

- Truth over marketing
- Diagnosis before action
- Local-first data
- Measurable before/after outcomes
- Standard Android first, optional Shizuku advanced mode
- No fake RAM or CPU boosters
